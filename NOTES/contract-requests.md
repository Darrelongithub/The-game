AGENT-G | package.json | Add dev dependencies typescript, tsx, @types/node and socket.io-client | Root tooling and strict external socket smoke test require them.
AGENT-G | packages/shared/src/contracts.ts | Define a privileged, local-only test oracle providing per-player expected finale decks, actual secret-frame recipient/owner trace, persisted counts per (roundId, playerId, clientUuid), verbatim dare passes, joker-guard weights and victim toxic-claim confidence | Public events expose neither deck ownership, stored submit counts, dare log contents nor joker guard weights, so an external client cannot prove secret isolation or idempotent persistence; do not disclose private decks to clients.

AGENT-B1 | packages/shared/src/contracts.ts | Add submitted player IDs and heat-down vote count to RoomView | Waiting dots and live vote counts cannot be derived from the public snapshot.
AGENT-B1 | packages/shared/src/contracts.ts | Specify ResponseValue mapping for pair_dare and debrief | RoundKind includes these kinds but ResponseValue does not; clients need an interoperable submission contract.
AGENT-A | packages/shared/src/contracts.ts | RoundView: add an optional structured payload — trait?: TraitId, about?: PlayerId, coding?: PromptCoding (or one payload?: Record<string, unknown>) | A rating / ios round cannot be answered legally without knowing WHICH trait and WHICH player it asks about: ResponseValue requires trait + about, but RoundView only carries promptText. Agrees with AGENT-D and AGENT-B1 on the same gap; apps/web ships a documented shim plus a graceful fallback meanwhile.
AGENT-A | packages/shared/src/contracts.ts | ClientToServerEvents.dare_pass: give it an ack (r: { ok: boolean; error?: string }) => void | The "I can't" escape REQUIRES a reason (<=140). Today the phone fires and forgets, so a rejected reason looks identical to an accepted one and the player never learns their excuse was not recorded.
AGENT-A | packages/shared/src/contracts.ts | RoomView: include the current beat on a reconnect snapshot — optional interlude?: InterludeView, reveal?: RevealView, finale?: FinaleView (broadcast-safe only) | Spec §1 promises reconnect = FULL snapshot, but interludes/reveals/finale are one-shot events with no replay. A phone that wakes mid-interlude shows a holding screen until the next event; one that reconnects after the finale never learns the night ended.
